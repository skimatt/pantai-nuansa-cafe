# Accessibility and SEO

## Accessibility
Semantic heading order, landmark navigation, skip-to-content, keyboard support, visible focus, ESC close dialogs, accessible labels, image alt, video captions, adequate text contrast, hit target sizes, reduced-motion, mute default, no flashing, intro skip. Horizontal gallery must have accessible non-scroll alternative/control. No information exclusive to hover or sound.

## SEO
Server-render/indexable HTML content, descriptive title/meta, Open Graph and social image, canonical URL, structured data only for verified business details, sitemap/robots as applicable, meaningful alt and media descriptions. Never use fictional address, hours, ratings, or menus in schema.org.

## Privacy
Avoid unnecessary analytics/tracking; external embeds/maps should respect consent and performance. Link to external map rather than mandatory heavy embed if possible.
