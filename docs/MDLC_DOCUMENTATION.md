# MDLC Research Traceability

## Metode
Gunakan Multimedia Development Life Cycle (MDLC) sebagai metode pengembangan sesuai proposal. Enam tahap teoretis: Concept, Design, Material Collecting, Assembly, Testing, Distribution. **Catatan:** berdasarkan pembahasan proposal, pelaksanaan mungkin dibatasi sampai Testing; pastikan teks proposal resmi sebelum menulis bahwa Distribution telah dilakukan.

## Deliverable tiap tahap
1. Concept: latar, tujuan, target audiens, kebutuhan multimedia, ruang lingkup, observasi/wawancara.
2. Design: storyboard, scene architecture, navigation flow, UI sketches, art bible, content schema, timeline.
3. Material Collecting: daftar aset, sumber/lisensi, foto/video resmi, generated illustrations, metadata, izin.
4. Assembly: struktur Next.js, JSON, Pixi, GSAP, audio/video, screenshot proses, commit history.
5. Testing: black-box, usability, ahli media bila relevan, responsivitas, performance, hasil dan keterbatasan.
6. Distribution: rencana/pelaksanaan deployment **hanya bila sesuai batasan penelitian dan telah dilakukan**.

## Proposal alignment
Judul kerja: “Pengembangan Aplikasi Multimedia Interaktif sebagai Media Promosi Pantai Nuansa Cafe Menggunakan Metode MDLC”. Periksa dokumen sumber resmi sebelum mengubah terminologi, batasan, rumusan masalah, dan metode uji. Implementasi website dan pendekatan visual yang lebih kaya adalah keputusan pengembangan; jangan mengklaim seluruh detail sudah tercantum di proposal.

## Research integrity
Tidak membuat data wawancara, responden, hasil uji, atau dampak kunjungan palsu. Semua screenshot dan metrik harus berasal dari implementasi nyata.
